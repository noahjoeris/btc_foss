
# Goal

Have a GitHub Pages site at `noahjoeris.github.io/btc_foss` that publishes a
timeline feed of my contributions to Bitcoin-related open source projects on
GitHub.

Used to audit my work and prove that I am active in the Bitcoin space.

## Design

- Runs a github action daily to farm my contributions and cultivate them in a
  presentable way.
- Should have symbols for each type of contribution (PR, review, commit, comment, discussion, etc).
- Similar style as the Github "activity" section on a user's profile. Related
  items should collapse into an expandable element. Grouped by project and then
  by time.
- Legibility is a must. Clean and compact UI.
